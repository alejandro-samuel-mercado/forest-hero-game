## 📖 Descripción / Historia  
En **Héroe del Bosque**, te conviertes en un héroe decidido a salvar a los animales de un incendio forestal causado por un malvado leñador.  
Mientras exploras, aprenderás sobre:  
- 🌱 **Impacto ambiental** de los incendios.  
- 💔 **Consecuencias ecológicas** para la fauna y flora.  
- ♻️ **Conciencia ambiental** y cómo nuestras acciones influyen en el planeta.  

El juego busca un **triple impacto**: educativo, social y ambiental.  

---

## 🎯 Objetivos y Misiones  
- 🐾 **Rescatar** la mayor cantidad posible de animales antes que el helicóptero se lleve el contenedor.  
- 💦 **Apagar** el fuego que arrasa con el bosque.  
- 🎮 **Participar** en minijuegos didácticos para aprender:  
  - 🌳 Ecología  
  - ❤️ Empatía  
  - 🤝 Habilidades sociales

## 🎮 Controles  

| Tecla / Botón | Acción |
|---------------|--------|
| ⬆️ Up         | Avanzar |
| ⬇️ Down       | Retroceder |
| ➡️ Right      | Mover derecha |
| ⬅️ Left       | Mover izquierda |
| ␣ Space       | Saltar |
| ⇧ Shift       | Correr |
| 🖱️ Click Izq. | Soltar animal / objeto |
| 🖱️ Click Der. | Mover cámara |
